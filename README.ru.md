# Componenta Iterator

[English version](README.md)

Утилиты для итераторов: повторный обход одноразовых источников, независимые курсоры, обратный обход, обход строк и преобразование итератора в массив.

Используйте пакет, когда библиотеке нужно поведение итераторов без зависимости от фреймворка коллекций.

## Установка

```bash
composer require componenta/iterator
```

## Требования

- PHP 8.4+
- `ext-mbstring`
- `componenta/arrayable` 1.x

## Связанные пакеты

| Пакет | Зачем нужен здесь |
|---|---|
| `componenta/stream-iterator` | Для больших PSR-7 потоков лучше использовать stream-iterator: он держит в памяти только текущий фрагмент. |
| `componenta/arrayable` | Некоторые итераторы раскрывают `toArray()` и могут использоваться как arrayable-объекты. |

## ReplayableIterator

`ReplayableIterator` оборачивает массивы, итераторы, объекты `IteratorAggregate` и генераторы. Он лениво кеширует уже прочитанные записи, поэтому одноразовый источник можно повторно обходить, не материализуя его полностью заранее.

```php
use Componenta\Stdlib\ReplayableIterator;

$iterator = new ReplayableIterator((function () {
    yield 'a' => 1;
    yield 'b' => 2;
})());

$iterator->toArray(preserveKeys: true); // ['a' => 1, 'b' => 2]
```

Объект сохраняет обычный API с одним курсором `Iterator`. Если два потребителя должны проходить один источник независимо или одновременно, используйте отдельные курсоры:

```php
$first = $iterator->cursor();
$second = $iterator->cursor();

$first->next();
// $second по-прежнему находится на собственной первой записи.
```

У каждого курсора своя позиция; общим остаётся только кеш прочитанных записей.
Внутренний кеш сохраняет повторяющиеся и `null`-ключи. По умолчанию `toArray()`
возвращает список значений. При `toArray(true)` сохраняются допустимые для массива
PHP ключи: `null` становится пустой строкой, при дублировании ключа остаётся последнее
значение. `count()` и `toArray()` проходят весь источник, не меняя позицию основного
курсора. Свойства `cacheSize`, `traversed` и `currentPosition` доступны только для
чтения; неудачный или прерванный обход не считается завершённым.

`replay()` — псевдоним `cursor()`, возвращающий новый независимый курсор.
Активный итератор нельзя клонировать; после полного обхода копия имеет независимую
позицию. Переданный источник находится под управлением обёртки: не перемещайте
его извне. Массив кешируется сразу; обычный итератор перематывается один раз при
создании, генератор читается с текущей позиции без перемотки.

Если источник выбросил исключение, дальнейшие чтения и продвижение курсоров
повторно выбрасывают то же исключение. Уничтожение Fiber при чтении источника
помечает обход неудачным с `LogicException`. При одновременном чтении запрос
некешированной записи отклоняется с `LogicException`, а кешированные записи
остаются доступны. Отклонение конкурирующего запроса не повреждает кеш и не
перемещает основной курсор.

## Обратный обход

`ReverseIterator` обходит конечный источник в обратном порядке с сохранением исходных
ключей. Материализация происходит при первой перемотке. `withIterable()` создаёт
новый итератор; `toArray()` использует правила ключей `iterator_to_array()`.

`ArrayListReverseIterator` обходит массив-список с последовательными целыми
индексами от нуля в обратном порядке, сохраняя индексы.

## StringIterator

Пакет требует расширение PHP `mbstring`. `forward()` достигает того же состояния конца строки, что и `next()`; нулевое смещение сохраняет курсор, а движение вперёд после завершённого обхода оставляет его завершённым.

`StringIterator` итерирует строку с поддержкой кодировки и методами управления курсором:

- `moveTo()`
- `forward()`
- `backward()`
- `read()`
- `remaining()`
- `peek()`

`moveTo()` выбирает существующий индекс символа от нуля и отклоняет позиции
за пределами строки. `read()`, `remaining()` и `peek()` не перемещают курсор.
`count()` возвращает число символов, `getEncoding()` — кодировку, `withString()`
создаёт итератор с той же кодировкой. `string`, `length` и `position` доступны
извне только для чтения; преобразование в строку возвращает исходную строку.

`forward()` и `backward()` принимают неотрицательное число шагов. Движение вперёд
достигает позиции конца строки (`isEnd()` — `true`, `current()` — `null`), движение
назад из этой позиции возвращает последний символ. Нулевой шаг сохраняет позицию.
Отрицательные шаги вызывают `InvalidArgumentException`.

## Преобразование в массив

`IteratorToArray` — трейт, реализующий `toArray()` через `iterator_to_array()`.
Публичный интерфейс преобразования — `Componenta\Arrayable\Arrayable`.
`ReplayableIterator` реализует собственное преобразование в список или массив с ключами.

## Разработка

```bash
composer install
composer test
```

CI проверяет метаданные Composer, синтаксис PHP и запускает Pest на PHP 8.4 и 8.5.

## Память

Итераторы повторного и обратного обхода используют дополнительную память. Они подходят для конечных последовательностей. Для больших PSR-7 потоков используйте `componenta/stream-iterator`, который держит только текущий chunk.
